# Student REST API

Энэхүү төсөл нь Express.js ашиглан хийсэн Оюутны мэдээллийг удирах (CRUD), хайлт хийх, хуудаслах (Pagination) болон алдаа боловсруулах боломжтой RESTful API юм.

---

## 🛠 Шаардлагатай технологиуд

- **Node.js** (v14 эсвэл түүнээс дээш)
- **npm** (Node Package Manager)
